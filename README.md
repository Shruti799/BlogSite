📝 Blog Platform

A full-stack blog platform built to enable users to create, read, update, and delete blog posts with high performance and secure authentication.
Designed with scalability and efficiency in mind, it optimizes data retrieval and ensures safe user sessions.

✨ Features

📰 Create, edit, and delete blog posts (CRUD operations)
⚡ Optimized database queries with indexing (40% faster retrieval)
🔐 Secure authentication using JWT
🌐 Google OAuth login with Passport.js
👤 User session management and protected routes
📱 Responsive and user-friendly UI

🛠️ Tech Stack

Frontend: React.js
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JWT, Passport.js (Google OAuth)
